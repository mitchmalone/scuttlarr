# Themes

One palette, rendered into every surface. `scuttlarr theme set <name>` changes all of
them at once; `scuttlarr theme build` regenerates the per-app files from the palette.

## Anatomy

```
themes/dracula/
├── palette.toml         # source of truth
├── ghostty              # rendered — one file per app, plain config the app reads directly
├── iterm2.itermcolors
├── launcharr.json       # merged into ~/.config/launcharr/config.json `themes.<name>`
├── borders.sh           # JankyBorders colours (launcharr regenerates from this)
├── p10k.zsh             # prompt colours (or starship.toml — see the terminal decision)
├── bat.tmTheme
├── delta.gitconfig
├── macos.sh             # AppleAccentColor / AppleHighlightColor / light-or-dark
└── wallpaper.jpg
```

`palette.toml`:

```toml
name = "Dracula"
appearance = "dark"          # drives NSGlobalDomain AppleInterfaceStyle
source = "https://draculatheme.com"
license = "MIT"

[ansi]                       # 16 terminal colours
black = "#21222c"  red = "#ff5555"  green = "#50fa7b"  yellow = "#f1fa8c"
blue = "#bd93f9"   magenta = "#ff79c6"  cyan = "#8be9fd"  white = "#f8f8f2"
bright_black = "#6272a4"  # … and the rest

[ui]                         # what launcharr, the bar, borders and the prompt consume
bg = "#282a36"  fg = "#f8f8f2"  dim = "#6272a4"
accent = "#bd93f9"  selection = "#44475a"  border = "#bd93f9"
warn = "#ffb86c"  danger = "#ff5555"
```

Templates live in `templates/<app>/`, with `{{ansi.blue}}` / `{{ui.accent}}` tokens.
Rendering is token substitution only — no logic in themes, no logic in templates. If an
app needs something a template can't express, the app gets a native theme file checked in
by hand next to the rendered ones, and the build leaves it alone.

## Rules

- **Rendered files are committed.** A theme directory works without the CLI and can be
  published on its own (Dracula model: "the scuttlarr Ghostty theme").
- **Light is first-class.** Solarized Light ships in v1 so no template can assume dark.
  `appearance` flips macOS light/dark with the theme.
- **Never redistribute paid themes.** Dracula Pro is the canonical overlay theme: users
  drop it in `~/.config/scuttlarr/themes/dracula-pro/` and it's picked up like any other.
- **Wallpaper is part of the theme.** Ships with each; overlay themes may omit it.

## Surfaces, v1

| Surface        | Mechanism                                                                                                                                                                       |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Terminal       | Ghostty or iTerm2 file, pending the terminal decision                                                                                                                           |
| Prompt         | p10k/starship colours                                                                                                                                                           |
| launcharr      | `themes.<name>` in config.json, `theme` set to it                                                                                                                               |
| Bar + borders  | launcharr reads its theme tokens; borders regenerated by it                                                                                                                     |
| bat / delta    | tmTheme + gitconfig include                                                                                                                                                     |
| macOS          | accent, highlight, light/dark, wallpaper via `osascript`                                                                                                                        |
| VS Code/Cursor | out of scope — they have their own theme ecosystems; document the matching upstream theme name in `palette.toml` (`editor_theme = "Dracula Theme"`) and let the user install it |
