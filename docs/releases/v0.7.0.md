<!-- v0.7.0 — launcharr is now scuttlarr -->

## Breaking changes

- **launcharr is now scuttlarr.** New name, new app (`scuttlarr.app`), new cask, new
  homes. Your config, themes, frecency, scripts, widgets, agent hooks and login item move
  on first launch with nothing to do (`~/.config/launcharr` → `~/.config/scuttlarr`, and
  the rest). On Homebrew, install the new cask; the old one is deprecated and points here:

  ```sh
  brew uninstall --cask launcharr && brew install --cask mitchmalone/tap/scuttlarr
  ```

  Upgrading with only `brew upgrade` keeps launcharr 0.6.0 — and installing scuttlarr
  without uninstalling launcharr leaves two launchers fighting over one hotkey.

- `~/.config/scuttlarr/widgets` reference widgets that imported `@launcharr/tui` keep
  building (the alias stays), but new ones should import `@scuttlarr/tui`.

## Highlights

**One product, not two.** The launcher and the scuttlarr desktop setup were separate
repos; now the launcher is a feature of scuttlarr. Install gets the bar and the launcher;
everything else is a rung you turn on — **Desktop** (AeroSpace tiling and borders,
rendered from your theme), **Theme** (one palette rendered into the app, the bar,
Ghostty, tmux, your editors and git), and **Machine** (the `scuttlarr` CLI: de-shined
macOS defaults, the shell, `doctor`, `remove` — shipped inside the app, every write
recorded in a manifest and reversible).

**Themes that reach every terminal, live.** `theme ⏎` switches the palette everywhere at
once: open terminals retint in place (no permission asked), tmux re-sources, VS Code and
Claude Code follow, and Ghostty can reload its config if you opt in. A theme policy can
pick for you — by macOS Focus, by system light/dark, or on a schedule. Bring your own
themes alongside the built-ins.

**Keep-awake you can leave for weeks.** `awake` holds until it says it will: "until I
turn it off" no longer expires, holds survive relaunches, crashes and reboots, and
`awake until oct 16` takes a date. With launch at login on, scuttlarr now relaunches itself if it crashes. Run
`scuttlarr sudoers on` once and every hold also switches macOS sleep off — lid closed on
battery stays up too, and a crash leaves no gap. **Away mode** is one checkbox for
remoting in over Screens from an iPad: it keeps an iPad-sized virtual screen (via
BetterDisplay) as the Mac's only display, so the iPad gets a native-size desktop instead
of a letterboxed one.

**The menubar knows more.** App updates from brew, the App Store, pnpm, npm and mise in
one cell, upgradable from the panel; every Claude and OpenAI account's usage shown as
pace, so the cell warns before you run out, not after; agent sessions follow you across
tmux and herdr; plugins are React cells and Bun services that declare their permissions
up front; and `!` hands a command to Ghostty through herdr or tmux.

**scuttlarr updates itself.** Every 6 hours it checks for a release; `updates ⏎` installs
it after verifying the checksum and the Developer ID signature (Settings → General turns
the check off, and off means no request).

## Performance receipts

Measured on the release build's code, 2026-10-01 (M5 Max, two displays, bar on, agents
monitor on, plugins running):

| Metric                         | Budget   | This release |
| ------------------------------ | -------- | ------------ |
| Hotkey → panel visible         | < 100 ms | 2.3 ms       |
| Cold start → hotkey registered | < 1 s    | 351 ms       |
| Idle memory (panel hidden)     | < 120 MB | 169 MB       |

Hotkey → panel is the native side of the summon path, median of 11 summons (1.5–3.4 ms).

**Idle memory is over budget**, and has been since the bar and plugins landed (first
measured 2026-09-16 at 157–177 MB; JOURNAL). The shrink is its own task. Helpers add to
it: two Bun plugin services (26 + 31 MB) and the Bluetooth helper (8 MB); the optional
JankyBorders child (372 MB) is not ours but runs because of us when Desktop borders are on.

## Install

```sh
brew install --cask mitchmalone/tap/scuttlarr
```

Or `curl -fsSL https://scuttlarr.com/install | sh`, or grab the dmg / zip below, or
build from source (README).
