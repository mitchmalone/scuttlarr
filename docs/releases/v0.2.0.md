> **Reconstructed after the fact** (2026-10-19). v0.2.0 shipped on 2026-08-09, as
> launcharr, with no release notes; this file is assembled from the commits and the docs
> at the tag.

## Breaking changes

- none (first tagged release)

## Highlights

- **The v1 launcher.** ⌥Space summons a non-activating panel that looks like a shell
  prompt; Esc hands focus back exactly where it was. Apps and System Settings panes,
  fuzzy-matched and frecency-ranked. `!git status ⏎` runs the command in iTerm2
  (Terminal.app as the fallback). First run shows the panel once with a hint line and
  registers a login item.
- **v1.1, Sol parity, scripts first.** Executables in `~/.config/launcharr/scripts/`
  declare a trigger word and answer queries (`docs/SCRIPTS.md`); clipboard history behind
  `clip` (copy on Enter, concealed types never recorded); inline math; custom links and
  config-defined extra global shortcuts.
- **v1.2, release core.** System commands (sleep displays, lock, empty trash, dark mode,
  …); ⌥⏎ secondary actions per row kind; opt-in browser bookmarks; the `:` emoji picker;
  URLs open directly, an Alfred-style search fallback, Raycast-style `{query}`
  quicklinks with an add-quicklink flow (browser choice, favicon); a menubar icon
  (summon / config / scripts / reindex / quit); a Settings window that is a form over
  `config.json`.

## Install

v0.2.0 was build-from-source only (Apple Silicon, Rust stable + pnpm):

```sh
git clone git@github.com:mitchmalone/launcharr.git
cd launcharr
pnpm install
pnpm tauri build
cp -R src-tauri/target/release/bundle/macos/launcharr.app /Applications/
```

The signed builds and the tap cask arrived with v0.3.0.
