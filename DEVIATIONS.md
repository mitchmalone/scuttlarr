# Deviations

Where this project diverges from the jig standard. Every entry has a justification and, where the divergence should eventually close, a trigger. Deviations are documented, never silent — an empty file means full compliance.

| Deviation                                                                                            | Why                                                                                                                                                                                                                                                                                                                                                   | Reconverge when                                                                                                                                                                                                                  |
| ---------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Primary deliverable is zsh, not TypeScript (`bin/`, `lib/`, `install/`, `defaults/`, `migrations/`). | The installer runs on a fresh Mac before Node, Homebrew, or anything else exists; it must be a shell script. Keeping the CLI in the same language keeps the distro hackable — "read it, fork it" — which is a product value (README principle 4). zsh over bash: macOS ships bash 3.2 but zsh 5.9, and zsh is the shell the distro configures anyway. | Never for the installer. The CLI if it grows logic that shell handles badly (structured config merging, theme rendering beyond token substitution) — then a compiled helper under `packages/`, still invoked from the shell CLI. |
| Tests are zsh scripts, not Vitest.                                                                   | Vitest can't exercise shell. TDD still applies: a behaviour gets a failing test in `test/` first. `apps/www` stays on Vitest.                                                                                                                                                                                                                         | A TS package appears — it uses Vitest.                                                                                                                                                                                           |
| No shellcheck in the gate.                                                                           | shellcheck does not parse zsh. `zsh -n` is the syntax floor; behaviour is covered by tests.                                                                                                                                                                                                                                                           | A zsh linter worth the dependency exists, or the CLI moves to bash (unlikely — see above).                                                                                                                                       |
| Homebrew tap is not the distribution channel.                                                        | A distro is installed by URL (`curl …                                                                                                                                                                                                                                                                                                                 | sh`), not `brew install`; the tap can't run `defaults`, LaunchAgents, or migrations. The release layer still tags and publishes notes; the tap fan-out job stays no-op.                                                          | launcharr-style packaging of the CLI alone becomes useful (e.g. `brew install scuttlarr` for an already-installed machine to get the CLI updated). |
